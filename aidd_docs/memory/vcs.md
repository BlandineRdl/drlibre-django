# VCS
## Platform
- Platform: GitHub, repository `BlandineRdl/drlibre-django` (private), reached with the `gh` CLI.

## Branches
- `main` holds the stable code; work happens on `feat/...` branches cut from `main`.

## Commits
- Conventional Commits.

## Pull requests
- Pull requests target `main` and merge by squash.

## Agent may
- AI should auto commit: after task done.
- An agent may push its branch and open a pull request alone.
