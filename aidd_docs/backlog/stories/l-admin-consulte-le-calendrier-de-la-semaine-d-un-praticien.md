# Story: L'admin consulte le calendrier de la semaine d'un praticien
**As** admin
**I want** ouvrir le calendrier de la semaine de chaque praticien
**So that** je contrôle ses disponibilités sans pouvoir les modifier

## Acceptance
- Chaque praticien a un calendrier de la semaine, en lecture seule : aucune action d'écriture n'y est proposée.
- Les heures sont dans le fuseau de l'hôpital du praticien, que la page nomme.
